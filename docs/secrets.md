# Secrets

What secrets exist, where each lives, and the rule.

## The rule

1. **Never commit a secret.** Not in code, not in config, not in a doc, not in
   a test fixture, not in a screenshot. `.gitignore` already excludes `.env*`,
   `*.local.json`, `.firebase/` and `*-service-account.json` — don't work
   around it.
2. **Never put a secret in client code.** Anything in `apps/web` or
   `apps/landing` ships to every browser. The Firebase *web config* (API key,
   project id) is public by design and is the only Firebase value allowed there.
3. **Agents don't hold secrets.** If a task needs one (a token, a login, a
   service account), write the exact command for James, assign the ticket to
   him, and stop. Never ask for a secret in chat, never paste one into a file.
4. **Secrets live in the platform's secret store**, never in the repo:
   GitHub Actions secrets for CI, Firebase Secret Manager for Functions, the
   developer's own keychain / CLI login for local work.

## What is safe to commit

- `firebase.json`, `.firebaserc`, `firestore.rules`, `firestore.indexes.json`.
- The Firebase web config object (API key, auth domain, project id, app id).
- `pnpm-lock.yaml`, `.nvmrc`, tool versions.

## What is never safe to commit

- Service-account JSON, refresh tokens, CI tokens, `gh`/`firebase` credential
  files, Secret Manager values, anything from `~/.config/gh`,
  `~/.config/configstore/firebase-tools.json`, or `.firebase/`.
- A child's save data or a real save code (test fixtures are synthetic).

## Guard rails

- `.gitignore` (above). Review it when adding a new tool.
- pnpm refuses post-install scripts unless a package is allow-listed in
  `pnpm-workspace.yaml` (`allowBuilds`); a new dependency that needs one gets a
  one-line reason there.
- Dependabot keeps `pnpm-lock.yaml` current (SF-45); a compromised dependency
  is the likeliest way a secret leaks — review post-install scripts in updates.
- `reviewer` checks every PR for key-shaped strings (`AIza…`, `-----BEGIN`,
  `ghp_`, `sk-`, `ya29.`) and for new files under `.firebase/`.
- If a secret is ever committed: rotate it **first**, then rewrite history
  (James), then note it in `.claude/memory/`. A pushed secret is compromised
  the moment it lands, however fast it is removed.
